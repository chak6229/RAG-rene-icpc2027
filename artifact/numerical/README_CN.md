# 保密审稿复算包

本包供指定编辑、审稿人及 artifact 评估人员核验。请通过投稿系统的保密补充材料入口分发，遵守目标会议的匿名与保密要求。论文正文由投稿系统单独提交。本包没有作者姓名、单位或联系方式，也没有可编辑的论文正文。

## 运行

解压后，在本文件所在目录使用 64 位 Python 3.9–3.12 执行：

```sh
python -m pip install -r requirements.txt
python -I reproduce.py
```

安装依赖通常需要联网；复算本身使用 CPU，无需 GPU、模型下载、账号或联网。成功后 `reproduced/ACCEPTANCE.json` 中的 `passed` 和 `full_bootstrap` 都为 `true`。重算数值在同目录 `RESULTS.csv`。`--quick` 可用于快速检查，但会跳过 bootstrap，不能代替完整复算。

## 可核验内容

包含 14 个分析单元、103 项对比：CoSQA 主确认、开发集 B/G、StaQC 确认、第三检索器、两套 T5 权重的旧匹配对照与新 25,600 组确认，以及完整 H 上执行阶段的收益、损害与核验工作量。分组、配对、检验族、随机种子和重采样次数沿用对应实验。英文 README 列出了表格与复算范围。

核心 B/G 从匿名候选位置的目标排名及已封存选择顺序重新计算 RR、精确随机期望和统计区间。其余阶段从匿名数值记录复算。数字并非直接从汇总表抄写。原始查询、代码文本、benchmark ID、qrels、权重、训练代码、原始人工评审返回、内部日志和未来计划不在包内。

这是缓存数值复算，不能核验模型是否重新产生了这些候选与排名，也不等于完整重训或历史生产流程恢复。`reference_tables/` 中的 T2–T4、T6–T7、T12–T15 在本包仅供查阅；人工评审仅提供聚合统计。两权重差值未决的结论保留，不能解释为等效。
