# 完整文档证据恢复正收益，候选风险筛选阻断有效核验

本轮完成 512 个不同 repository 查询、9,665 个候选的四折验证。恢复原流程的完整 84 维输入后，纯改写和融合的候选择优均获得正 ΔMRR；同容量 46 维对照为负。新增 CE 条件核验与 bootstrap 不确定性竞争选择未增加实际收益。当前瓶颈是候选级 harm 筛选在核验前过滤掉大多数正收益动作。

## 同容量输入对照

两种输入使用同一 LightGBM 架构、五成员、repository-keyed Poisson 采样、每 query 平均总权重 1。84 维包含 46 基础/多 seed 特征、28 真实文档相关性排名统计、10 repository-OOF 文档/锚点监督特征。改写用 document mask，融合用 joint mask。

| 无候选层 harm 门、正均值选择 | 改写 ΔMRR | 融合 ΔMRR |
|---|---:|---:|
| 46 维控制 | −0.004931 | −0.005634 |
| 84 维完整输入 | **+0.015428** | **+0.016398** |
| 完整输入增量 | +0.020359 | +0.022032 |
| 配对 repository 95% 区间 | [+0.005942,+0.034924] | [+0.007987,+0.036393] |

完整输入的全候选 MAE、harm Brier 和 harm AUC 也均改善。固定每折 13 次、总 52 次采用的排序诊断为 +0.016670/+0.012375；有害数为 18/19。上述正收益说明完整输入改善选择能力；候选层不使用 harm 门的策略不承担风险认证或部署用途。这是历史开发池上的固定 OOF 预测区间，不包含重拟合变化或前瞻确认。

## 两种门分别造成什么结果

**候选级 harm 预测筛选**：fit192 内完整三折 pipeline OOF 从预定网格选择 τ，目标为非空且经验采用内 harm≤5% 的最大收益。所有消融用同一主 τ。该筛选在追加核验之前生效。

| 同 τ 自然策略 | 改写 ΔMRR | 改写采用/害/正 | 融合 ΔMRR | 融合采用/害/正 |
|---|---:|---:|---:|---:|
| 完整输入 | −0.001217 | 90/7/5 | +0.000021 | 64/3/2 |
| 同容量 CE 列置零 | −0.001089 | 80/6/4 | −0.000008 | 56/3/0 |
| CE 普通竞争者 | −0.001136 | 76/6/3 | −0.000008 | 58/3/0 |
| CE 不确定性竞争者 | −0.001136 | 77/6/3 | −0.000008 | 58/3/0 |

完整输入原本选中的正收益查询从 103/111 降为 5/2；正收益总量保留 **0.377%/0.089%**，损失总量保留 6.522%/0.047%。完全回退的 354/393 个查询中，原本有益者为 98/107 个。防损与误拒同时发生，融合的损失压制更强，但正机会也大量消失。

冻结留出预测进一步定位方向识别问题：原选中正/害/零动作的平均 harm 预测分别为改写 .268/.310/.166，融合 .234/.265/.145。harm 预测区分真实 ΔRR 是否非零的 AUC 为 **.754/.744**，在非零动作内区分害与正的 AUC 为 **.590/.565**。它具有变化强度信号，方向区分相对弱。这里“真实变化”是离线目标 RR 标签，不等于完整可见检索列表是否改变，不能作为在线 gold 门。

**独立统计认证**：fit192/risk192/held128 保持互斥；仅预定 CE 不确定性主策略在四折×两 family 共 8 次认证，单项 δ=.05/8，目标采用内真实 harm≤10%。8 项均未通过，7 项非空策略的实测 harm 都≤10%，但 CP 上界为 .166–.921；另一项零采用。零 harm 情况仍需至少 49 个接受 repository。全部 fold 认证后回退原查询，ΔMRR=0。

因此，本轮不是因为留出有害率持续超过10%而全回退；候选预测门首先压缩有效收益和接受量，独立证书再因样本功效不足拒绝部署。增加校准规模可解决证书功效，不能恢复已经被候选筛选抹去的正收益。

## 新不确定性模块的独立作用

核验由固定 query 文本 SHA256<.25 路由；普通与 UQ 策略在同一批 eligible 查询核验。每次8文档槽，包含当前安全 winner。UQ 用五个共享 bootstrap 成员的 `E[max(mu_rival−mu_winner,0)]` 选择 eligible Top5 中的竞争者。

UQ 改变了改写11/融合4个候选核验计划，所有对应实际 ΔRR 差均为0。普通与UQ成本均为改写24 query/192 slots、融合16/128；UQ实际截断未padding CE token分别少225/174，不能将这点成本变化当收益提升。CE-full相对CE-zero改写增量−.000048、融合0。

成员差异是经验收益头 bootstrap 不确定性；共享上游监督证据未采样，不称完整 Bayesian posterior 或完整 T5 UQ。均值残差和 harm 事件头是独立预测头，不拼装成已证明一致的后验 law。新增 UQ 本轮没有独立正收益证据。

## 保留与后续设计

保留完整84维收益分支及其训练权重量纲修复，作为后续同输入对照；不将其收益重命名为UQ贡献。新增CE/UQ核验保存为研究支路。正式前置问题判断、软件约束与候选质量过滤不删除；STABLE/CURRENT与旧四分之一惩罚配置未改。

下一设计针对**变化概率与收益方向的区分**：让强收益候选能进入核验，再由动作证据判断是否伤害原查询的成功文档，而不是先按低 harm 预测排除几乎所有高收益候选。新策略需要独立训练方向监督和重新认证；不根据本轮已见 risk/held 结果调 τ、挑消融胜者或更改10%目标。本轮尚未执行这一步，不记录为已改善。
