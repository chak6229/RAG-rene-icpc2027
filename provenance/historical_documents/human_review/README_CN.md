# 人工评审与补审

数据来源统一记为**人工评审**。两位独立审阅者以 A/B 匿名代号表示，均已同意共享匿名标签和理由；A 补审独立完成已由研究负责人确认。原标签、逐条理由、unknown 与分歧保持不变。

## 评审数据

- 初评：128 个查询、383 条不同改写、327 个代码面板。A/B 每人还评估 128 条查询明确度，合计 1,676 条记录。
- 补审：同一批查询增加的代码面板，每人 344 条，共 688 条；不增加样本查询数或审阅者人数。
- 样本：原八层各抽 16 条，共 128 条、120 个关联组；完整抽样设计和权重随包提供。
- 统计：一致性、10 类加权事件、24 类加权错误类型、6,144 条相关性识别界、48 组诊断和抽样包络。

逐条数据在 `data/`，已验收统计在 `reference/`，说明与文件清单见 [README.md](README.md)。匿名编号已跨文件统一；导出前后按“审阅者、判断类型、标签及理由”核对完全一致。身份、原始查询/代码编号、原返回附件及过程时间不随包提供。查询和代码原文需按上游许可取得，指纹可供匹配。

## 运行

在仓库根目录安装依赖后执行：

```powershell
python human_review/reproduce.py --output reproduced/human_review
python human_review/verify_human_reviews.py
```

相关性识别界从匿名 Top3 面板、原标签及补审标签重算；加权事件和类型比例从随附的冻结逐查询事件标记重算。识别界与抽样区间分别报告，不将样本加权诊断当作全 H 的正收益确认。本文评估的是已展示面板，不是全语料重新标注。
