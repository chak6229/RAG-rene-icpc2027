# 原研究、本地重建与自动执行扩展的对应

原研究为 SSQR。下表核对的原始数值依据本次留存的公开 arXiv HTML 版本，不能据此断言正式出版版与该版本逐项相同。论文中的方法引用与具体实现约定分别保留；原作者 checkpoint、原始训练 CSV 和未公开生产聚合未恢复。

| 原研究命题或使用情景 | 公开原文依据 | 本研究的对应条件与结果 | 判定范围 |
| --- | --- | --- | --- |
| ENTR 相对随机位置选择有优势 | 原表 4 的 CodeBERT ENTR 为 0.2221，RAND 为 0.1886 | 同一明确重建下，AdvTest 2,048 查询桥接 ENTR−RAND20 best3 为 −0.00435302，组 bootstrap 95% 区间为 [−0.00822558,−0.00033732] | 本重建的原数据桥接未出现原报告正向差值；因模型及生产聚合身份不等同，不作原生产系统的严格数值复原判定 |
| 位置优势能否延续到外部查询来源 | 原结果的外部适用性扩展 | CoSQA 限额 H 7,718 查询、1,963 组，ENTR−RAND20 best3 为 −0.00083652，组 bootstrap 95% 区间 [−0.00325479,+0.00154146]；两种预定区间均在 ±0.005 内 | 支持指定重建与逐查询 best3 约定下的实质等效；不把该容忍范围推广为普遍阈值 |

原数据桥接与 CoSQA D 的直接效应差为 −0.00672102，组 bootstrap 95% 区间 [−0.01364477,+0.00045645]，保留 34 个跨域共享关联组的协方差。跨条件效应差未决，因此不能仅凭两个域各自的方向给出域差异结论。不同条件还改变语料、目标标注和难度，不单独识别查询措辞的因果影响。

实施差异与进一步诊断见实现保真度表、六种生成配置、聚合审查和有限训练对照。1,024 次更新敏感性不能覆盖历史 93,750 次更新的全部影响；它不改变原冻结 CoSQA 对照，也不建立历史训练差异的完整归因。
