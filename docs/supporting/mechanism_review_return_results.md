# Agreement and weighted diagnostics of the final review returns

The researcher reports that two reviewers completed the human assessment. We analyze their submitted final returns, covering 128 sampled queries (120 groups), 383 unique rewrites and 327 code panels per reviewer. Agreement estimates describe these final returned labels; original independent labels before subsequent review have not been reconstructed, so the estimates should not be presented as original independent-assessment agreement.

The semantic exact agreement was 76.5% (nominal Cohen κ=0.525). Code relevance agreement including unknown was 53.8% (κ=0.371); the jointly judged 0/1/2 subset covered 260/327 panels (79.5%) with linear-weighted κ=0.569. Unknown code labels were 2 for A and 67 for B. Semantic classes differed for 90 rewrites; including issue types, 106 rewrites differed. Code labels differed for 151 panels. All submitted judgments and disagreements were retained without automated adjudication.

Using the original eight-stratum query weights for the fixed H8530 frame, the query proportion with at least one rewrite marked drift/malformed by both raters was 35.0% (conservative finite-frame 95% CI 9.9%–69.6%). The proportion with any rewrite not marked preserved by at least one rater was 75.5% (39.6%–95.4%), which includes unknown and disagreements. The weighted proportion with RR loss after verification while both raters marked the adopted rewrite preserved was 12.9% (7.6%–40.3%); displayed non-target code marked fully relevant by both occurred in 12.0% (1.3%–46.2%). These overlapping indicators describe marked query events, not a causal decomposition of retrieval loss. Intervals reflect finite-frame sampling alone and omit label error and review-version uncertainty.

The returns expose differences in how added wording, query ambiguity, missing code context and partial functionality are treated. Full disagreement analysis is now provided in review_disagreement_discussion.md. Its complete class-pair counts distinguish 47 A-drift/B-preserved cases from seven in the reverse direction, 65 numeric/unknown code differences from 86 numeric-grade differences, and 35 clarity differences. These are item counts rather than weighted population proportions.

Three reproducibly selected examples connect the labels to exact cached outcomes. For `python output colors from a string`, adding `json` is drift for both reviewers but leaves target RR unchanged. For `get index of an item in list python`, an article-only, both-preserved action moves the target from rank 16 to 18 while a both-preserved alternative reaches rank 14. For `set python request headers`, both reviewers grade a displayed non-target Session.headers.update implementation fully relevant even as known-target RR moves from one to one-half. All three examples allocate zero actual cross-encoder pairs, so a RIDGE_verified stage name is not evidence of actual verification in those cases. They are illustrative and do not estimate prevalence.

The review evidence supports a post-hoc diagnostic account without identifying unique causal contributions.
